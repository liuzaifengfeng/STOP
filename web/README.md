# STOP-C6 Web 工具箱

Vue 3 + TypeScript + Vite 的 Web Bluetooth PWA。浏览器直接连接 ESP32-C6，云端只负责托管静态页面和固件文件。

## 本地开发

```powershell
cd web
npm install
npm run dev
```

`localhost` 可使用 Web Bluetooth。部署环境必须使用 HTTPS。推荐 Chrome 或 Edge，并确保电脑/Android 设备具有 BLE 功能。

## 双设备连接与配对

侧边栏“操作说明”无需连接设备即可阅读，包含双端指示灯查表、蜂鸣器规则、配对与本地使能步骤、急停恢复、电压 / 电流 / 失联保护、低压停机回执和网页联调说明。说明以当前固件实际行为为依据；控制端绿灯只代表已配对且急停触点正常，不能作为被控端已供电的判断。

页面顶部的“控制端”和“被控端”各有独立的连接按钮。连接控制端时选择 `STOP-C6`，连接被控端时选择 `STOP-C6-RX`；两台可同时在线。点击设备卡片后，“设备概览”“设备配置”“无线诊断”“固件升级”只作用于该设备，不会混用参数、诊断记录和 OTA 进度。

“配对与联调”页面会读取两端配对标志及目标 BLE MAC，并核对是否互相指向对方。控制端自动发送配对请求；被控端在输出断开时可按住本地键 8 秒，或点击网页按钮，开启 30 秒配对窗口。网页不能远程合闸；配对后恢复通电仍需本地按键确认。两端连接后，可在被控输出断开时发送双向 E22 诊断包，观察对端是否收到。

被控端向控制端做联调或在“无线诊断”页发送数据时，若两台 BLE 设备都已连接，网页会先确认被控输出断开，然后让控制端发送 STOP 并暂停安全心跳 10 秒供接收。窗口到期自动恢复心跳；失去心跳或收到 STOP 时被控端保持断电锁存，恢复供电仍需本地按键确认。

首次使用此版本须分别通过 USB 刷入新固件：控制端项目标识 `STOP_TX`，被控端为 `STOP_RX`。之后网页 OTA 会按当前设备的产品编号和硬件修订发起升级，并检查所选镜像中的项目标识；旧固件与新项目标识不同，无法通过当前 OTA 路径跨版本升级。控制端和被控端的固件文件分别位于 `STOP/.pio/build/esp32-c6-devkitm-1/firmware.bin` 和 `Assused/.pio/build/esp32-c6-devkitm-1/firmware.bin`。

## 云端固件

固件 URL 必须允许网页来源跨域读取（CORS），内容必须为原始 `.bin`，不能返回下载 HTML 页面。界面会在浏览器内计算 SHA-256，然后按 `Document/BLE_PROTOCOL.md` 分块发送。

## 安全边界

当前网页和 C6 尚未实现维护身份认证与量产固件签名。不要将本工具部署到不可信环境，也不要将当前 OTA 能力用于正式安全产品。

## GPIO6 故障时的临时调试入口

更新 Assused 被控端固件和网页后，在“配对与联调”页连接被控端：

1. 点击“被控端进入配对模式（30 秒）”，替代本地长按 8 秒。
2. 配对完成、控制端急停释放且安全心跳有效后，点击“临时调试：安全使能输出”，替代本地长按 3 秒。该操作会实际接通输出。
3. “断开输出”可主动断电；急停、心跳超时和电源保护仍然有效。故障恢复后不会自动重新使能。

使能仍检查 E22、已配对、连续 3 个安全心跳、心跳未超时、配对窗口关闭、VIN 9～30 V、VOUT <2 V、电流 <5.5 A、INA226 告警清除成功和 OTA 未进行；硬件故障锁存时拒绝使能。网页会读回实际输出状态，拒绝原因详见被控端串口。旧固件不支持使能命令，请先更新固件。

临时 BLE 命令 0x14：请求负载为 1 字节（0=断开，1=安全使能），成功响应为空；安全条件不满足返回 SAFETY_LOCKOUT，非法参数返回 INVALID_ARGUMENT。命令不模拟 GPIO6 电平，串口 key=released 仍表示物理引脚读数。
