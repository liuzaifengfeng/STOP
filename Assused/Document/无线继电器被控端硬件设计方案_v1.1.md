# 无线继电器被控端主控——硬件设计方案

**版本**：v1.1（原型验证版）  
**日期**：2026-09-14  
**适用阶段**：实验室原理样机、受控电源条件下的功能和负载兼容性验证

> 本版本优先考虑结构简单、成本可控、便于手工调试。它不是经过认证的安全急停设备，也不具备车载浪涌、工业 EMC 或功能安全等级声明。满载及复杂负载测试必须从低电压、限流条件逐级进行。

---

## 1. 目标与边界

### 1.1 目标

- 输入：12～48V DC，单向供电。
- 目标持续电流：20A；在完成热测试前，首板只按短时20A验证。
- ESP32-C6 负责状态机、BLE/Wi-Fi维护和数据记录。
- E22-400T22S 作为主要无线控制链路。
- 使用高边功率MOSFET切断正极母线。
- 测量输出电压、负载电流，并实现过流告警和关断。
- 面向电机、舵机、DC/DC、机载电脑等混合负载，提供可调启动斜率。
- 上电、复位、固件未就绪、无线失联时默认断开。
- 只有收到按钮端有效的“允许供电/启动”安全报文后才允许闭合。

### 1.2 原型阶段限制

- 输入必须来自稳定、带限流功能的实验室电源或已知特性的电池组。
- 不宣称承受汽车 load dump、长线强浪涌或感性负载全部回馈能量。
- PCB首板没有完整反接保护；依靠防呆连接器、醒目标识和输入熔断器防止误接。
- RC软启动只控制MOSFET栅极和输出电压上升速度，不等同于恒流限流。
- 无线链路和单片机不构成认证安全回路。

## 2. v1.1 技术决策

| 项目 | v1.1决定 | 原因与代价 |
|---|---|---|
| 主控与无线 | 保留 ESP32-C6 + E22-400T22S | 固件和模块基础不变，缩短原型周期 |
| 主功率开关 | 保留 LTC7004 + IRFB4110 | 电路成熟、TO-220便于散热和更换 |
| 默认状态 | 改为硬件默认断开 | MCU复位或未初始化时不向复杂负载供电 |
| 启动条件 | 有效E22启动报文 + 链路健康 + 无故障 | 避免上电自动启动和失联后继续供电 |
| 电流检测 | 保留 INA228 + 0.5mΩ分流器 | 成本略高，但精度、软件和调试便利性好 |
| 电压检测 | INA228测输出电压；ESP32 ADC粗测输入电压 | 可核对命令状态与真实输出状态 |
| 过流保护 | INA228 ALERT + 低成本逻辑门直接禁止驱动 | 减少对中断响应的依赖，但仍依赖INA228初始化 |
| 反接保护 | 首板删除原错误P-MOS方案 | 100V低阻P-MOS方案不现实；理想二极管控制器会增加成本和复杂度 |
| 输入保护 | 熔断器 + TVS占位 | 原型可吸收部分小瞬态，但不作完整浪涌保证 |
| 软启动 | 保留并允许换RC参数/旁路 | 混合负载是否适合慢上电必须实测 |
| 3.3V电源 | 首板暂保留 AMS1117-3.3 | 便宜、易采购；代价是发热和余量较小 |
| Wi-Fi/BLE | 仅用于维护、诊断、OTA | 两者共享ESP32-C6的2.4GHz射频，不能算两条独立安全链路 |

## 3. 系统框图

```text
VIN+ 12～48V
  │
  ├─ F1 25A～30A DC熔断器
  │
  ├─ TVS1 输入瞬态抑制（原型辅助保护）
  │
  ├─ Q1 IRFB4110 高边N-MOS
  │      └─ U1 LTC7004 栅极驱动 + 可调RC软启动
  │
  ├─ RSHUNT 0.5mΩ / 2W / Kelvin
  │      └─ U2 INA228 电流检测、输出电压检测、ALERT
  │
  └─ VOUT+ → 复杂负载母线

VIN- / GND ─────────────────────────→ VOUT-

常电控制支路：
VIN+ → 80V级宽压Buck模块 → 5V
                         ├─ E22-400T22S
                         └─ AMS1117-3.3 → ESP32-C6 + INA228 + 逻辑门

输出许可链：
E22有效启动报文 → ESP32状态机 → MCU_ENABLE ─┐
INA228无过流 → ALERT_OK ────────────────────┼→ 74LVC1G08 → LTC7004 INP
硬件默认下拉/掉电/复位 ─────────────────────┘
```

说明：本方案切断的是正极主供电。负载负极仍与控制板共地，因此不等同于电气隔离；如果负载通过USB、网线屏蔽层或其他电源供电，仍可能发生倒灌。

## 4. 输入、熔断与原型保护

### 4.1 输入熔断器

- F1放在输入正端、靠近接线端子。
- 初始建议使用25A或30A慢断直流熔断器，额定电压不低于60V DC。
- 最终规格应根据线束允许电流、负载启动电流和实测波形调整。
- 熔断器负责最终短路能量隔离；INA228和MOSFET关断不能替代熔断器。

### 4.2 反接处理

v1.1不装原v1.0中的FDMS86181反接电路，因为FDMS86181实际为N沟道器件，不能按P-MOS方案使用。

原型阶段采用：

- 有方向的防呆插头；
- 输入端醒目的正负极丝印；
- 红黑线束和测试前万用表确认；
- 输入熔断器。

PCB可预留未来理想二极管控制器和背靠背100V N-MOS的位置，但首板允许不焊。

### 4.3 TVS

- 输入端预留SMBJ/SMCJ封装，首板可试装SMBJ48A或依据实际电源上限重新选择。
- TVS必须位于熔断器之后并紧靠输入端。
- SMBJ48A在额定浪涌电流下钳位电压可能高于LTC7004和60V Buck的绝对最大值，因此这里只作为小瞬态和ESD辅助抑制，不作为浪涌等级保证。
- 首板不得在长线、高能感性电源或车辆电源环境直接测试。

## 5. 控制电源

```text
VIN 12～48V
  └─ 80V级宽压Buck模块 → 5V / ≥1A
       ├─ E22-400T22S
       └─ AMS1117-3.3 → 3.3V
            ├─ ESP32-C6
            ├─ INA228
            └─ 74LVC1G08
```

### 5.1 Buck模块要求

- 输入额定上限至少80V，不再使用只标称60V的普通LM2596HV/TPS54360模块作为默认选项。
- 原型可采用XL7015类80V模块，但必须核对模块输入电容耐压、二极管和实际芯片来源。
- 输出5V、持续能力至少1A。
- 模块输入端并联100nF陶瓷和47µF/100V电解；输出端按模块要求配置并增加220～470µF低ESR电容。

### 5.2 3.3V轨

- AMS1117-3.3输入、输出电容按所购器件数据手册配置。
- ESP32-C6附近放置10µF + 1µF + 100nF去耦。
- 3.3V轨建议增加220µF低ESR电容，用于缓冲射频发射电流跃变。
- AMS1117需大面积铺铜。连续开启Wi-Fi时必须测量其外壳温度和3.3V最低值。
- 如果出现过热、复位或3.3V跌落，v1.2优先改为5V→3.3V小型Buck，而不是继续增大电容掩盖问题。

### 5.3 LTC7004 VCC

```text
VIN → 4.7kΩ / 0.5W → LTC7004 VCC
                         ├─ 12V齐纳 → GND
                         ├─ 10µF → GND
                         └─ 100nF → GND
```

- 齐纳阴极接VCC、阳极接GND。
- VCCUV可先悬空，使用内部约7V欠压门限。
- 12V输入时应实测VCC启动和MOS栅源电压，确认不会反复进入UVLO。

## 6. 高边MOSFET与可调软启动

### 6.1 主电路

```text
VIN ── Q1 Drain
       Q1 Source ── RSHUNT ── VOUT

LTC7004：
TGUP ── RG 100kΩ ── Q1 Gate
TGDN ─────────────── Q1 Gate
Q1 Gate ── 10Ω ── CG 47nF/100V ── GND
TS ───────────────── Q1 Source
BST ── CB 1µF ────── TS
```

注意：CG连接在MOS栅极与GND之间，不是连接在TS与GND之间。

### 6.2 可调参数

- RG默认100kΩ，并预留10kΩ、47kΩ、220kΩ替换位置。
- CG默认47nF/100V，并预留22nF、100nF、220nF替换位置。
- 预留 `JP_FAST_START`：仅在确认负载允许时旁路大阻值启动路径，用于快速上电对比实验。
- 默认组合理论输出斜率约2V/ms，48V上升约24ms，但真实波形受MOS阈值和负载行为影响。

### 6.3 复杂负载风险

混合负载可能在缓慢升压时出现：

- DC/DC反复启动、进入欠压锁定并产生脉冲电流；
- 机载电脑在电压不足时复位；
- 舵机控制器异常初始化；
- 电机驱动器输入电容和电机制动回馈形成额外冲击；
- MOS在线性区承受较大瞬时功耗。

因此v1.1把RC网络作为“可调实验项”，而不是已经验证的通用软启动。必须同时观察VIN、VOUT、负载电流和Q1温度。

### 6.4 MOSFET与散热

- Q1：IRFB4110，100V TO-220。
- 20A、25°C时按4.5mΩ估算损耗约1.8W；热态损耗会更高。
- 必须安装带绝缘措施的散热片，并测量壳温。
- PCB预留第二只并联MOS的位置可以作为调试选项，但在未评估线性区均流前不默认并联。
- 首板逐级测试：12V/2A → 12V/10A → 24V/10A → 48V/10A → 目标工况。

### 6.5 TS负向钳位

- D2从GND接至TS：阳极接GND，阴极接TS。
- 器件反向耐压至少100V；SS34不再使用。
- 板上小功率D2只处理驱动器TS引脚和短线寄生电感保护。
- 电机、电磁阀等高能感性负载必须在负载端设计续流、TVS或制动吸收，不能把全部能量交给板上小二极管。

## 7. 默认断开与输出许可

### 7.1 硬件默认状态

```text
74LVC1G08 OUT ── 1kΩ ── LTC7004 INP
                              │
                            47kΩ
                              │
                             GND
```

- INP外接47kΩ下拉。
- 控制逻辑未供电、ESP32复位或GPIO高阻时，INP保持低，Q1断开。
- 禁止使用将INP上拉到3.3V的默认闭合方式。

### 7.2 低成本关断逻辑

74LVC1G08两输入与门：

- 输入A：`MCU_ENABLE`，由ESP32输出；外接100kΩ下拉。
- 输入B：`ALERT_OK`，来自INA228 ALERT开漏输出；外接10kΩ上拉。
- 输出：连接LTC7004 INP。

运行逻辑：

| MCU_ENABLE | ALERT_OK | 主MOS |
|---:|---:|---|
| 0 | 任意 | 断开 |
| 1 | 1 | 允许闭合 |
| 1 | 0（过流） | 立即断开 |

这条路径使INA228告警不必等待ESP32中断处理后才能关断。但INA228的门限仍需由ESP32在启动阶段正确配置，所以它不是完全独立的模拟硬件断路器。

### 7.3 上电状态机

```text
上电/复位
  → INP硬件下拉，输出断开
  → 初始化3.3V、INA228、E22
  → 配置快速过流门限并清除旧告警
  → 验证输出电压应接近0V
  → 等待按钮端有效启动报文和连续健康心跳
  → MCU_ENABLE=1，开始软启动
  → 检查VOUT上升、电流和无线心跳
  → 任一故障：MCU_ENABLE=0并锁存断开
```

建议原型策略：

- 急停报文、心跳超时、E22故障、过流、ESP32复位均立即断开。
- 断开后不自动重试启动。
- 必须重新收到新的有效启动序列才允许再次闭合。
- BLE和Wi-Fi只能读取状态、调试和升级，不能直接置位 `MCU_ENABLE`。

## 8. 电流与电压检测

### 8.1 INA228连接

```text
Q1 Source ── RSHUNT 0.5mΩ ── VOUT+
               │        │
             Kelvin+  Kelvin-
               │        │
             INA228 IN+ IN-

INA228 VBUS ← VOUT+
INA228 VCC  ← 3.3V
INA228 ALERT → ALERT_OK
```

- VBUS改为测量VOUT，而不是Q1之前的VIN。
- 这样既能计算负载功率，也能在断开后检查输出是否仍然带电。
- 采用±40.96mV量程；20A时分流压降10mV，25A时12.5mV。
- 分流器功耗：20A时0.2W，40A时0.8W；必须使用合适脉冲能力和低TCR的四端/Kelvin器件。

### 8.2 建议保护门限

混合负载可能具有较高启动峰值，首轮建议使用分层策略：

- 快速硬关断门限：35～40A，INA228 ALERT锁存模式；用于明显短路和严重浪涌。
- 软件持续过流门限：初始25A，持续时间通过实测确定，例如100～500ms。
- 稳态告警门限：20A附近，只告警和记录，不立即切断。

上述值仅用于原型起点。最终必须依据线束、端子、MOS SOA、熔断器曲线和真实启动波形调整。

### 8.3 输入电压粗测

增加ESP32 ADC分压：

```text
VIN ── 680kΩ ──┬── ESP32 ADC
                ├── 27kΩ → GND
                └── 10nF → GND
```

- 用于诊断输入电压、欠压和输入跌落，不用于精密计量。
- ADC引脚前可增加1kΩ串联电阻和3.3V钳位保护。
- 必须通过万用表进行两点校准。

## 9. ESP32-C6与E22接口

| 功能 | GPIO | 备注 |
|---|---:|---|
| LTC7004 `MCU_ENABLE` | GPIO4 | 输出，外部100k下拉；经74LVC1G08后到INP |
| INA228 ALERT | GPIO5 | 输入，同时进入硬件与门 |
| INA228 SDA | GPIO6 | I2C |
| INA228 SCL | GPIO7 | I2C |
| E22 TXD → ESP RX | GPIO17 | UART；调试日志优先走USB Serial/JTAG |
| E22 RXD ← ESP TX | GPIO16 | UART |
| E22 AUX | GPIO15 | 输入；核对上电配置脚影响 |
| E22 M0 | GPIO14 | 输出 |
| E22 M1 | GPIO13 | 输出；若使用原生USB需重新分配 |
| VIN ADC | GPIO0 | 仅作输入电压粗测 |
| 状态LED | GPIO18 | 避免使用启动模式脚GPIO8 |

在原理图冻结前必须根据实际ESP32-C6-MINI-1封装、USB使用方式和下载接口再做一次引脚审查。

## 11. PCB布局重点

### 11.1 20A路径

- `VIN端子 → 熔断器 → Q1 → 分流器 → VOUT端子`必须短、直、宽。
- 建议2oz铜、上下层并联大面积铺铜，并使用密集过孔连接。
- 首板预留裸铜开窗，以便焊接铜编织带或2～4mm²铜线加固。
- 不能只凭“10mm线宽”宣称满足持续20A；必须通过温升测试确认。
- 端子、熔断器座、分流器焊盘和过孔往往比铜箔更先成为发热点。

### 11.2 Kelvin采样

- INA228的IN+/IN-从分流器焊盘内侧单独引出。
- 采样线成对、等长、远离栅极和开关节点。
- INA228靠近分流器，输入可预留小阻值串联电阻和差分滤波电容位置。

### 11.3 驱动与射频

- LTC7004、CB和MOS栅极回路紧凑放置。
- CG及10Ω阻尼电阻靠近Q1栅极。
- ESP32和E22天线分别靠近板边，避开散热片、功率铜皮和线束。
- 功率路径与天线区域尽量位于PCB相反两侧。
- Buck模块远离INA228采样线和两副天线。

### 11.4 测试点

至少预留：VIN、VOUT、5V、3.3V、LTC_VCC、Q1_GATE、INP、MCU_ENABLE、ALERT、SDA、SCL、E22_AUX和GND测试点。

## 12. 原型验证流程

### 阶段A：控制板与默认断开

1. 不安装Q1或断开功率负载，仅给控制支路12V限流供电。
2. 检查5V、3.3V和LTC7004 VCC。
3. 确认ESP32复位、下载固件和看门狗重启期间INP始终为低。
4. 模拟ALERT拉低，确认即使MCU_ENABLE为高，INP仍被关闭。
5. 检查E22收发、心跳超时和启动报文状态机。

### 阶段B：低压阻性负载

1. 12V、2A阻性负载验证开关和电流读数。
2. 示波器同时观察Q1栅极、VOUT和ALERT。
3. 人为制造短时过流，确认ALERT直接切断INP并锁存。
4. 验证断开后INA228 VBUS读数下降。

### 阶段C：容性与混合负载

1. 先单独连接DC/DC和机载电脑，逐一记录启动电流和最低工作电压。
2. 再逐步加入舵机、电机驱动器和其他负载。
3. 分别测试47nF、100nF等软启动参数。
4. 检查是否发生DC/DC反复启停、电脑复位或舵机异常动作。
5. 记录每种组合的VIN、VOUT、电流、启动时间和Q1壳温。

### 阶段D：逐级升压与满载

1. 12V、24V、36V、48V依次测试，每级都从限流状态开始。
2. 20A测试前先验证端子、熔断器座、铜箔和MOS在10A下的温升。
3. 首次20A只做短时测试，确认无异常后再延长时间。
4. 记录环境温度、各热点温度和3.3V最低电压。

### 阶段E：故障注入

- E22断电、AUX卡死、UART断线、心跳超时。
- ESP32复位、看门狗复位、OTA重启。
- INA228断线或I2C异常。
- 输出短路和负载启动峰值。
- 输入电压骤降、重新上电。

所有故障均应得到同一基本结果：输出断开且不自动重新闭合。

## 13. v1.2候选升级项

只有在v1.1实测暴露需求后再加入：

1. 100V N-MOS理想二极管反接保护。
2. 100V级浪涌截止或热插拔控制器。
3. 独立模拟比较器和硬件故障锁存。
4. 5V→3.3V同步Buck替代AMS1117。
5. 双背靠背主MOS，阻断负载向输入倒灌。
6. 两级预充：预充电阻支路 + 主MOS硬闭合。
7. 接触器或安全继电器及辅助触点反馈。

## 14. v1.1结论

v1.1保留ESP32-C6、E22、LTC7004、IRFB4110和INA228，删除错误反接电路，并以默认断开、熔断器、可调软启动、输出电压反馈和低成本过流禁止逻辑构成最小可验证原型。

该架构适合回答以下原型问题：

- E22控制链路在目标环境中是否稳定；
- 混合负载采用多快的上电斜率最可靠；
- 实际启动峰值和持续电流是多少；
- IRFB4110、PCB铜箔和端子的温升是否可接受；
- 过流、复位和失联时能否可靠断开。

在这些实测数据得到之前，不把“48V/20A持续运行”“通用复杂负载软启动”或“安全急停”作为已经验证的能力。
