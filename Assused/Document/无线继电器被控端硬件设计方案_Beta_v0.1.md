# 无线继电器被控端——Beta硬件方案

**版本**：Beta v0.1  
**日期**：2026-09-14  
**定位**：6S锂电池和实验室限流电源条件下的最低复杂度功能样机

> 本版本用于尽快验证无线控制、默认断开、5A母线开关以及电压电流采集。它不具备工业浪涌、反接、热插拔或认证急停能力。

---

## 1. Beta目标

- 常用电源：6S锂电池，工作范围约18～25.2V。
- 实验室推荐测试范围：9～30V DC。
- 受控输入上限：36V DC；不得在36V附近热插拔。
- 额定输出电流：5A。
- ESP32-C6 + E22-400T22S保持不变。
- 默认断开；收到按钮端有效启动报文后闭合。
- 收到急停、无线失联、MCU复位或过流告警后断开。
- 使用P沟道MOSFET进行高边开关。
- 使用INA226测量高边电流和输出电压。
- 不安装反接保护、TVS和RC软启动。
- TVS和简单栅极调速元件只保留空焊盘。

---

## 2. 系统结构

```text
BAT+ / VIN+
  │
  ├─ F1 7.5A～10A DC熔断器
  │
  ├─ Q1 NVMFS5113PL，-60V贴片P-MOS高边开关
  │
  ├─ RSHUNT 10mΩ / 1W / Kelvin
  │      └─ INA226：电流 + VOUT电压 + ALERT
  │
  └─ VOUT+ → 小车负载母线

BAT- / GND ─────────────────→ VOUT-

常电支路：
VIN → TPS5430成品降压模块（5V）─┬─ E22-400T22S
                                └─ AMS1117-3.3 → 3.3V
                                                   ├─ ESP32-C6
                                                   ├─ INA226
                                                   └─ 74LVC1G08

输出许可：
ESP32 MCU_ENABLE ─┐
INA226 ALERT_OK ──┼→ 74LVC1G08 → 高压NPN → Q1 Gate
默认下拉 ─────────┘
```

## 3. 输入条件和删减项目

### 3.1 允许的输入

| 输入场景 | Beta结论 |
|---|---|
| 6S锂电池18～25.2V | 推荐场景 |
| 12V/24V实验室电源 | 推荐场景 |
| 30V实验室电源 | 可测试，必须限流 |
| 36V实验室电源 | 仅作受控边界测试，不允许热插拔 |
| 36V标称电池 | 禁止，满电电压可能超过36V |
| 车辆、长线、高能电池热插拔 | 禁止 |

### 3.2 防反接

Beta不安装主动防反接器件，采用：

- XT60或其他有方向的连接器；
- PCB醒目正负极丝印；
- 红黑线束；
- 输入串联7.5A～10A熔断器。

注意：熔断器不能保证所有反接情况下电路不损坏，它主要用于限制严重故障能量。

### 3.3 浪涌保护

- Beta默认不安装TVS。
- PCB保留一个SMBJ封装，标记 `DNP`。
- 输入电容使用63V耐压。
- 禁止带电插拔、长线供电以及电机回馈未经处理的测试。
- 如果示波器测得VIN尖峰接近或超过36V，停止测试；应改装TVS或升级到耐压更高的电源与检测器件。

## 4. 高边P-MOS开关

### 4.1 器件

- Q1：NVMFS5113PL，P沟道，-60V，Power 56 / SO-8FL类贴片功率封装。
- 导通电阻约14mΩ（VGS=-10V）。
- 5A、25°C估算导通损耗：

```text
P = I²R = 5² × 0.014 ≈ 0.35W
```

热态损耗会增大，但在5A下通常可由PCB铜皮散热。Q1漏极焊盘应连接上下层大面积铜皮并布置散热过孔，不再设置插件散热片。

### 4.2 栅极驱动

```text
Q1 Source ───────── VIN
Q1 Drain  ───────── RSHUNT → VOUT

Q1 Source ── 47kΩ ── Q1 Gate       默认关断
Q1 Source ──|<|───── Q1 Gate       12V齐纳，阴极接Source
Q1 Gate   ── 10kΩ ── Q2 Collector
Q2 Emitter ───────── GND
Q2 Base ── 10kΩ ─── 74LVC1G08 OUT
Q2 Base ── 100kΩ ── GND
```

- Q2选用耐压不低于60V的NPN，例如MMBT5551；若希望更容易手焊，可用TO-92高压NPN。
- 逻辑低或控制电源掉电时，Q2截止，Q1栅极被47kΩ拉回Source，输出关闭。
- Q2导通时将Q1 Gate拉低，12V齐纳限制VGS，防止栅氧损坏。
- 10kΩ集电极电阻在36V输入下限制齐纳和Q2电流。

### 4.3 不安装RC软启动

- 不增加专用栅极电容。
- PCB可保留Gate-GND电容和串联电阻焊盘，默认DNP。
- 首次带复杂负载启动时，将实验室电源限流设置为5～7A。
- 若DC/DC反复重启、保险丝熔断或MOS过热，再考虑在后续版本恢复软启动或预充电。

## 5. INA226电压电流检测

### 5.1 连接

```text
Q1 Drain ── RSHUNT 10mΩ ── VOUT+
              │       │
             IN+     IN-
               INA226

INA226 VBUS ─────────── VOUT+
INA226 VS   ─────────── 3.3V
INA226 ALERT ────────── ALERT_OK
INA226 SDA  ─────────── ESP32-C6 GPIO18
INA226 SCL  ─────────── ESP32-C6 GPIO19
```

- INA226共模和VBUS工作上限为36V，因此适用于6S电池和受控的30V以内测试。
- 不允许母线尖峰超过36V。
- RSHUNT采用10mΩ、1W、低TCR、Kelvin采样电阻。
- 5A时压降50mV、功耗0.25W。
- INA226可直接读取VOUT、电流和计算功率，不再需要ESP32 ADC母线分压。

### 5.2 过流起始参数

- 稳态额定：5A。
- 软件告警起点：5.5A。
- 快速关断起点：7A～8A，后续根据真实启动电流调整。
- ALERT使用锁存模式；故障后由软件确认电流和输出状态，再允许清除。

INA226最快转换时间约140µs。ALERT适合Beta保护和诊断，但不能替代熔断器。

## 6. 默认断开逻辑

74LVC1G08两输入与门：

- 输入A：ESP32 GPIO21 `MCU_ENABLE`，外接100kΩ下拉。
- 输入B：INA226 `ALERT_OK`，开漏输出外接10kΩ上拉。
- 输出：经10kΩ驱动高压NPN Q2。

| MCU_ENABLE | ALERT_OK | Q1状态 |
|---:|---:|---|
| 0 | 任意 | 断开 |
| 1 | 1 | 闭合 |
| 1 | 0 | 断开 |

启动流程：

```text
上电
 → Q1硬件默认断开
 → 初始化ESP32、INA226、E22
 → 配置过流阈值
 → 检查VOUT应接近0V
 → 等待按钮端有效启动报文
 → MCU_ENABLE=1
 → Q1闭合
```

以下条件立即令 `MCU_ENABLE=0`：

- 收到有效急停报文；
- E22心跳超时；
- E22初始化或运行故障；
- INA226过流告警；
- MCU复位、看门狗或OTA；
- 输出状态与命令不一致。

断开后不得自动重启，必须收到新的有效启动序列。

## 7. 控制电源

### 7.1 主方案：TPS5430成品降压模块

采用已装好电感、二极管及反馈网络的TPS5430成品降压模块：

- 芯片输入上限为36V，实际模块还受板载电容、二极管和布局限制。
- 模块输出为5V；Beta控制支路按不低于1A连续输出能力验收。
- 6S满电25.2V适用；不得把36V标称电池接入本模块。
- 模块应选带固定安装孔或可靠焊盘的版本，不使用仅靠排针承受振动的连接方式。
- 收货后先核对输入电容耐压不低于50V，再空载确认输出为5.0V。

```text
VIN → TPS5430模块 → 5V ─┬─ E22-400T22S
                         └─ AMS1117-3.3 → 3.3V
                                            ├─ ESP32-C6
                                            ├─ INA226
                                            └─ 74LVC1G08
```

E22-400T22S采用5V供电，以保证22dBm档位的发射功率和通信距离；其UART接口仍为3.3V逻辑电平，可直接连接ESP32-C6。ESP32-C6、INA226和74LVC1G08由AMS1117-3.3供电。

AMS1117按ESP32-C6约0.5A峰值估算，瞬时耗散约为：

```text
P = (5V - 3.3V) × 0.5A ≈ 0.85W
```

原型可用，但SOT-223散热焊盘必须铺铜并布置散热过孔；若实测稳态温度过高或ESP32射频工作时3.3V跌落，后续改用1A级低压差LDO或第二级同步Buck。

该方案的优点：

- 模块成本低且容易采购；
- 主PCB不用处理Buck电感、续流二极管和反馈布局；
- TPS5430模块直接形成E22需要的5V电源；
- 模块损坏时容易替换，适合原型阶段。

代价：

- 市售模块用料和布局差异较大，不能只依据“3A”标称判断能力；
- TPS5430为异步Buck，模块尺寸和低负载效率一般；
- 36V是芯片绝对输入边界，不能承担6S系统的插拔尖峰；
- AMS1117存在约0.5～0.85W峰值热耗散，布局和铜皮面积不能省略；
- 5V和3.3V电源轨都需要本地储能电容。

### 7.2 后续集成备选

如果后续希望把电源集成到主PCB，可选择：

1. **SGMICRO SGM61620**：4.2～60V输入、2A同步Buck，集成上下功率MOS和内部补偿，耐压余量大；需要外置电感、反馈电阻和输入输出电容。
2. **Silergy SY21102**：5～40V输入、2A异步Buck、SOT23-6，外围和成本较低；需要外置电感及续流二极管，效率和耐压余量低于SGM61620。
3. **XLSEMI XL1509-3.3**：4.5～40V输入、2A、SOP8，便宜且容易焊接；开关频率只有150kHz，电感和电解电容较大，不适合追求紧凑布局。

首板按用户选定的TPS5430成品模块实施；进入成本或体积优化阶段再改成裸Buck芯片。

不使用TPS82130，因为它的输入上限只有17V，不能连接6S满电电池。

### 7.3 去耦

- VIN入口：47µF/63V + 1µF/50V + 100nF/50V。
- TPS5430模块输入端就近增加100nF/50V陶瓷电容；模块已有的大电容不替代主板VIN入口储能电容。
- 5V总线在E22附近增加100µF低ESR储能电容。
- AMS1117输入、输出各放置10µF；输出电容类型和ESR应满足所购AMS1117厂商数据手册要求。
- 3.3V总线增加100～220µF低ESR储能电容。
- ESP32附近：10µF + 1µF + 100nF。
- E22附近：47～100µF + 10µF + 100nF。
- INA226和74LVC1G08各自放置100nF去耦。

### 7.4 ESP32-C6引脚分配

在当前E22、按键、USB和调试串口连接的基础上，新增信号分配如下：

| 功能 | ESP32-C6 GPIO | 模组焊盘 | 方向 | 备注 |
|---|---:|---:|---|---|
| ADC | GPIO0 / ADC1_CH0 | 12 | 输入 | 仅接0～3.3V模拟量；输入前端应限压并建议增加RC滤波 |
| INA226 SDA | GPIO18 | 24 | 双向 | I2C SDA，4.7kΩ上拉至3.3V |
| INA226 SCL | GPIO19 | 25 | 输出 | I2C SCL，4.7kΩ上拉至3.3V |
| WS2812 DATA | GPIO20 | 26 | 输出 | 靠近首颗灯串联220～470Ω；WS2812使用5V供电时建议增加74AHCT1G125等3.3V转5V电平缓冲 |
| MCU_ENABLE | GPIO21 | 27 | 输出 | 接74LVC1G08输入A，并用100kΩ下拉保证复位和上电期间默认关闭 |

当前完整占用关系应按下表检查原理图和固件：

| GPIO | 当前用途 | 说明 |
|---:|---|---|
| GPIO0 | ADC | ADC1_CH0 |
| GPIO1 | E22 NRST | 模块复位输出 |
| GPIO2 | E22 M0 | 模式控制 |
| GPIO3 | E22 M1 | 模式控制 |
| GPIO4 | E22 RXD | ESP32 UART1 TX；该脚同时属于启动配置相关脚，复位采样期间不得被外部异常拉动 |
| GPIO5 | E22 TXD | ESP32 UART1 RX；该脚同时属于启动配置相关脚，需确认E22上电/复位电平不会改变启动配置 |
| GPIO6 | KEY | 按键输入 |
| GPIO12 | USB D- | ESP32-C6原生USB固定功能 |
| GPIO13 | USB D+ | ESP32-C6原生USB固定功能 |
| GPIO14 | E22 AUX | 模块状态输入 |
| GPIO16 | UART0 TXD | 下载/日志调试 |
| GPIO17 | UART0 RXD | 下载/日志调试 |
| GPIO18 | INA226 SDA | I2C数据 |
| GPIO19 | INA226 SCL | I2C时钟 |
| GPIO20 | WS2812 DATA | 灯带数据输出 |
| GPIO21 | MCU_ENABLE | 74LVC1G08输入A |
| GPIO22 | 蜂鸣器 | 当前固件已定义，保留不用作本次新增信号 |

GPIO8、GPIO9和GPIO15属于启动配置相关脚，本版不分配给上述新增功能。GPIO7和GPIO23暂留扩展。原理图中如果仍将 `DP` 标在GPIO7，应改为GPIO13；USB必须连接为GPIO12=`D-`、GPIO13=`D+`。

## 9. PCB和测试要求

- 5A功率路径建议2oz铜、上下层铺铜，净宽至少3～5mm；端子额定电流不低于10A。
- INA226采样线必须从分流器焊盘内侧Kelvin引出。
- Q1漏极功率焊盘采用大面积铜皮，建议上下层合计约500～650mm²并使用散热过孔；Q1、分流器和输入端子附近预留温度测量位置。
- TPS5430模块靠近VIN入口放置，输入和地线短而粗；上车时必须机械固定。
- E22与ESP32天线远离P-MOS、Buck和大电流走线。

建议测试顺序：

1. 12V、限流0.5A验证5V、3.3V和默认断开。
2. 12V、1A阻性负载验证开关和INA226。
3. 12V、5A验证压降与温升。
4. 6S电池通过限流电源模拟器验证18～25.2V。
5. 分别接入DC/DC、机载电脑、舵机和电机控制器。
6. 最后连接真实6S电池，首次串联熔断器并避免热插拔。
7. 用示波器测量VIN最大尖峰；超过36V立即停止测试并恢复浪涌抑制方案。

## 10. Beta结论

以6S锂电池为主要电源后，Beta可以采用：

```text
ESP32-C6 + E22
+ NVMFS5113PL贴片P-MOS高边开关
+ INA226高边电压电流检测
+ TPS5430成品降压模块（5V）+ AMS1117-3.3
+ 74LVC1G08过流禁止
+ 输入熔断器
```

相较v1.1，删除LTC7004、IRFB4110、主动反接保护、已安装TVS和RC软启动，功率指标从48V/20A降至6S/5A。控制电源保留5V和3.3V两级，以保证E22满功率发射。该方案足以快速验证无线链路、默认断开、复杂负载启动和电压电流采集，同时把高能量和耐压风险显著降低。
