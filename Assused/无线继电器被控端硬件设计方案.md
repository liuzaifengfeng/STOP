# 无线继电器被控端主控 — 硬件设计方案

**版本**：v1.0（设计定稿）
**日期**：2026-08-18
**作者**：丰

---

## 1. 项目概述

基于 ESP32-C6 + E22-400T22S（LoRa）的无线继电器主控：装置**串联在直流电源母线上**，通过射频远程控制母线通断，支持电流监测与过流保护。

**核心特性**：
- 直流母线 12~48V，单向电流，额定 20A
- LoRa 无线远程开/关（E22-400T22S，433MHz，SX1262 方案，通信距离可达 5km）
- 高边开关（切断正极，负载完全断电）
- 容性负载软启动（LTC7004 RC 斜坡限流，兼容大部分常见负载）
- 精密电流监测（INA228，20-bit，I2C 直读）＋硬件过流警报（75µs 响应）
- 防反接保护（无源 P-MOS，可恢复）
- **上电默认闭合**（fail-closed：固件异常/掉电后重新上电即恢复通电）
- **三路无线通路**：LoRa（E22-400T22S）+ WiFi 6 + BLE 5.0（ESP32-C6 原生），多通路互为备份与验证

## 2. 已确认的技术决策

| 决策点 | 结论 | 说明 |
|---|---|---|
| 母线规格 | 12~48V DC / 20A / 单向 | MOS 耐压 ≥60V，按 100V 选型留余量 |
| 控制板供电 | 母线常电端取电 | 母线断开时控制电路仍存活 |
| 开关拓扑 | **高边** N-MOS + LTC7004 | 负载完全断电，安全干净 |
| 软启动 | LTC7004 TGUP 串 RC | 兼容容性负载，浪涌可控 |
| 过流保护 | **INA228**（I2C + ALERT） | 数字精密监测 + 硬件快速关断 |
| 反接保护 | 无源 P-MOS（3 元件） | 可恢复，压降仅 Rds(on)×I |
| 供电架构 | 宽压 Buck → 5V → LDO → 3.3V | 用现成模块，元件极少 |
| 默认状态 | **上电默认闭合** | INP 加 10k 上拉 |
| 输出保护 | 输出端跨 SMBJ48A TVS | 吸收负载侧瞬态 |
| 板子形式 | **PCB 打样** | 见 §12 布局指南 |

## 3. 系统框图

```
母线正(12~48V) ──┬─ [反接保护 P-MOS ×2] ──┬─────────────┬── 系统正 (VIN)
                │   S─D，正接自导通        │             │
                │                          ├─ SMBJ58A → GND        （输入 TVS）
                │                          ├─ 47µF/100V 电解 → GND （输入储能）
                │                          ├─ LTC7004 VCC 稳压     （4.7k + 12V 齐纳 + 电容）
                │                          ├─ 宽压 Buck 模块 → 5V
                │                          │      ├─ E22-400T22S（5V 供电）
                │                          │      └─ AMS1117-3.3 → 3.3V
                │                          │            ├─ ESP32-C6
                │                          │            └─ INA228
                │                  高边开关：
                │                  N-MOS(D) ← 系统正
                │                  N-MOS(S) ─┬─ LTC7004 TS
                │                           ├─ SS34 肖特基 → GND（感性关断钳位）
                │                           ├─ 10Ω→CG(47nF/100V) → GND（软启动）
                │                           └─ 0.5mΩ 采样电阻 → 输出正
                │                                                   ├─ SMBJ48A → GND（输出 TVS）
                │                                                   └─ 负载 +
母线负(=GND) ───┴───────────────────────────────────────────────────── 负载 −
```

## 4. 电源树

```
母线 12~48V
 ├─ 反接保护 P-MOS → 系统正
 │    ├─ LTC7004 VCC：4.7k(≥0.5W) 串联 → 12V 齐纳(0.5W) → VCC，并 10µF + 0.1µF
 │    ├─ 宽压 Buck 模块（TPS54360 或 LM2596HV，输入耐压 ≥60V）→ 5V
 │    │    ├─ E22-400T22S VCC        （2.3~5.5V 宽压，5V 保证 22dBm 满功率）
 │    │    └─ AMS1117-3.3 → 3.3V     （ESP32-C6 + INA228 + 上拉/逻辑）
 │    └─ INA228 VBUS 采样输入（≤85V）
 └─ GND（系统地，与母线负共地）
```

**要点**：
- Buck 模块前加 **SMBJ58A TVS**（钳位 ~64V），防母线开关瞬态损坏模块（48V 母线必须，模块输入耐压按 60V 选）
- AMS1117 压差 1.7V：3.3V 峰值约 0.65A（ESP32 满射频 + LoRa 发射）→ 功耗 ~1.1W，SOT-223 需铺铜散热
- E22-400T22S 发射电流约 110mA@22dBm，5V 轨轻松承载

## 5. 反接保护（无源，可恢复）

```
母线正 ── S (P-MOS) D ── 系统正
              │
              G ── 47kΩ ── GND
              │
          12V 齐纳（G-S 间，阴极端朝 G）
```

- **原理**：正接时 Vgs=-48V 被齐纳钳到 -12V → 导通；反接时 Vgs=+0.7V → 截止，体二极管反偏，全板安全
- **选型**：**2× FDMS86181 并联**（-100V / 8mΩ / PowerPAK SO-8）。20A 分流后各 ~0.8W，铺铜散热
- 不需要 MCU 参与，接对就通、接错就断，重新正接自动恢复

## 6. 高边开关与软启动（LTC7004 + IRFB4110）

### 6.1 驱动电路（照抄 datasheet Figure 5 参数）

```
        LTC7004 (MSOP-10, Exposed Pad=GND 必须焊接到 PCB)
VCC     ← 4.7k←系统正；VCC-GND 并 12V 齐纳 + 10µF + 0.1µF
VCCUV   ← 悬空（UVLO 7.0V，VCC=12V 满足）
INP     ← ESP32 GPIO + 10k 上拉 3.3V（默认闭合，见 §9）
OVLO    ← GND（不用过压锁定）
TGUP    ← 100kΩ(RG) → N-MOS 栅极          ← 软启动路径
TGDN    ← 直连 N-MOS 栅极                  ← 关断路径（不受 RC 影响）
TS      ← N-MOS 源极
         + SS34 肖特基（阴极接 TS）→ GND   ← 感性负载关断钳位
         + 10Ω → CG(47nF/100V) → GND       ← 软启动 RC 网络
BST     ← 1µF(CB) → TS                     ← 自举电容
GND     ← 系统地
```

### 6.2 关键参数与原理

| 参数 | 值 | 说明 |
|---|---|---|
| Vgs(on) | **12V** | 内部电荷泵把 BST-TS 稳压到 12V，IRFB4110 完全增强 |
| 软启动时间 | ~10~20ms | τ=RG×CG=100k×47nF≈4.7ms，Vgs 指数爬升 |
| 浪涌抑制 | 数百 µF~几 mF 负载 | 如 1mF 电容 20ms 充到 48V → 浪涌仅 ~2.4A |
| 关断速度 | µs 级 | TGDN 1Ω 下拉直连栅极，绕过 RC |
| CB 取值 | 1µF | 需满足 CB > QG/1V + 10×CG ≈ 0.63µF |
| CG 耐压 | 100V | 栅极最高 ≈ 母线+12V = 60V |
| 阻尼电阻 | 10Ω | 串在 CG 支路防栅极高频振荡 |

### 6.3 开关管选型

- **IRFB4110**（100V / 180A / 4.5mΩ@Vgs=10V / TO-220）
- 20A 导通损耗：20² × 0.0045 ≈ **1.8W**
- **必须加散热片**：TO-220 裸片 RθJA≈62°C/W 温升达 112°C；加 20×20×10mm 铝散热片后温升 ~20-35°C

## 7. 电流监测与过流保护（INA228）

```
0.5mΩ/2512 合金采样电阻（2W 规格）串在 MOS 源极与输出正之间
INA228：
  IN+/IN-   ← 跨采样电阻（开尔文四线连接，见 §12）
  VBUS      ← 系统正（≤85V 共模，48V 母线安全）
  VCC       ← 3.3V（2.7~5.5V）
  A0/A1     ← GND（I2C 地址 0x40）
  SDA/SCL   ← ESP32 I2C
  ALERT     ← 开漏，10k 上拉 3.3V → ESP32 GPIO
```

**工作点**：20A × 0.5mΩ = 10mV 满量程差分（INA228 满量程 ±163.84mV，量程余量 16 倍）；采样电阻损耗仅 0.2W。

**过流保护闭环（双层）**：
1. **硬件层**：INA228 阈值寄存器（如设 25A）→ ALERT 拉低（**75µs 响应**）→ ESP32 中断 → GPIO 拉低 LTC7004 INP → 关断
2. **软件层**：I2C 轮询 20-bit 电流值 → 可调阈值、记录事件、远程上报

## 8. 主控与射频接口

```
E22-400T22S（LoRa, SX1262, 410~493MHz, 默认 433.125MHz）
  VCC   ← 5V（2.3~5.5V 宽压；5V 保证 22dBm 满功率）
  GND   ← GND
  TXD   → ESP32 RX（3.3V TTL 兼容，直连）
  RXD   ← ESP32 TX
  M0/M1 ← GND（透传模式固定）；如需空中唤醒/低功耗可接 GPIO 配置
  AUX   → ESP32 GPIO（模块状态指示）
  天线  ← 433MHz 弹簧天线/IPEX
```

- UART 电平：模块输出 3.3V TTL，与 ESP32-C6 直连，**无需电平转换**
- ESP32-C6 供电 3.3V（AMS1117）

## 9. 默认闭合的实现（fail-closed）

LTC7004 的 INP 内置 1MΩ 下拉（出厂默认断开）。改为默认闭合：

```
3.3V ── 10kΩ ──┬── LTC7004 INP
               └── ESP32 GPIO（推挽）
```

- **上电时序**：母线通电 → VCC（12V 齐纳）建立 → LTC7004 使能 → INP 被 10k 上拉为高 → **负载立即通电**（软启动 RC 压住浪涌）→ 约几百 ms 后 ESP32 启动接管
- **固件控制**：GPIO 拉低 = 断开；拉高/高阻 = 闭合
- ⚠️ 行为说明：**任何一次重新上电，负载都会先通电**（软启动限流）；若要求"上电保持断开、固件就绪后再决定"，由固件在启动早期主动拉低 INP 实现（但仍存在上电瞬间 ~ms 级导通窗口）

## 12. PCB 布局指南（20A 功率板）

### 12.1 功率回路（20A 载流）
- 功率路径（母线正→P-MOS→N-MOS→采样电阻→输出端子）：**铺铜 ≥10mm 宽，推荐 2oz 铜厚**（1oz 时需更宽 + 开窗镀锡加厚）
- 采样电阻两端的功率走线 → 负载；**采样信号线从采样电阻焊盘根部引出（开尔文四线）**，避免功率电流流经 INA228 的信号走线
- 输入 47µF 电解 + SMBJ58A **紧靠输入端**，TVS 优先贴近接线端子

### 12.2 LTC7004 布局（关键）
- Exposed Pad（GND）**必须大面积焊接**到地铜皮（散热 + 电气）
- BST 自举电容（1µF）**紧贴 BST-TS 引脚**，走线越短越好
- 栅极驱动环路（TGUP/TGDN/TS ↔ MOS 栅源）**包围面积最小化**，否则高 di/dt 引起振铃
- CG(47nF/100V) 放栅极附近，10Ω 阻尼电阻与 CG 串联就近放置
- 12V 齐纳 + 电容紧贴 VCC 引脚

### 12.3 分区与隔离
- **高压区（母线/高边，最高 60V）与低压区（3.3V/5V 控制）分区布局**，低压区远离功率开关节点（开关节点是噪声源）
- INA228 靠近采样电阻；其模拟输入走线加宽并远离开关节点
- 系统地单点连接：功率地（母线负）与控制地在**输入端一个点**汇合，避免地弹干扰 3.3V

### 12.4 散热
- IRFB4110（TO-220）：**必须加散热片**（1.8W），散热片固定孔预留
- 2× FDMS86181：PowerPAK 焊盘下方铺大面积铜皮（>2×2cm）并打散热过孔阵列
- AMS1117：SOT-223 焊盘铺铜

### 12.5 天线
- 433MHz 天线区域**净空**（无铜皮/走线），远离金属散热片和开关节点；IPEX 座距板边 ≥5mm

### 12.6 其他
- 高压爬电间距：母线 48V 按 60V 等级，线距 ≥0.6mm（推荐 ≥1mm）
- 电源/信号连接器加测试点（TP）：VIN、5V、3.3V、VCC、INP、ALERT、输出

## 13. 上电调试清单

1. **空载上电**：可调电源 12V 限流 0.5A → 检查 5V / 3.3V / LTC7004 VCC=12V
2. 万用表量 INP 电平：应为高（默认闭合）；输出端应有电压
3. I2C 扫描确认 INA228（0x40）应答，读电流≈0
4. LoRa 收发测试：遥控命令 → 输出通断，AUX 状态正确
5. 接小电流负载（1A）验证采样读数准确（校准增益）
6. **满载 20A 测试**：红外测温仪检查 IRFB4110 散热片（<70°C）、P-MOS、Buck 模块
7. 过流测试：可调电子负载设 25A → 验证 ALERT 触发关断（75µs 硬件响应）
8. 反接测试（最后做，确认保护生效后断开）：母线反接 → 无电流 → 正接恢复

## 14. 安全注意事项

- **48V / 20A 是高能量等级**（~1kW），调试时全程使用限流电源，先小电流验证
- 反接保护测试时**先断开负载**，观察保护动作后立即恢复正接
- 感性负载（电机/继电器/电磁阀）关断瞬间的高压反峰由 TS 肖特基 + 输出 SMBJ48A 吸收；大电感负载建议**在负载端再并联续流二极管**
- 高温、短路、过流保护依赖 INA228 ALERT + 固件双闭环，量产前务必做失效模式测试

## 15. 固件接口约定（后续开发）

- 框架：Arduino-ESP32 或 ESP-IDF
- LoRa：透传模式（M0=M1=0），自定帧协议（帧头 + 命令 + CRC），命令集：`闭合 / 断开 / 查询状态(含电流、母线电压、温度) / 设阈值`
- **多通路仲裁层**：LoRa / WiFi / BLE 三通路统一进入命令仲裁（见 §16），支持备份、重复确认、心跳监测与状态回读
- 默认状态机：上电 → 默认闭合 → 收到命令后按命令执行；LoRa 掉线看门狗策略待定（如"N 秒无心跳自动断开"为可选策略，需与默认闭合权衡）
- INA228：轮询电流/母线电压/能量累计；ALERT 中断处理过流事件并记录
- 参数持久化：EEPROM/NVS（阈值、地址、密钥）

## 16. 多通路无线架构（LoRa + WiFi + BLE）

ESP32-C6 原生支持 WiFi 6（802.11ax, 2.4GHz）与 BLE 5.0，与外部 LoRa 模块（E22-400T22S, 433MHz）构成**三频段独立通路**，零新增硬件。

### 16.1 通路对比

| 通路 | 频段 | 距离 | 速率 | 功耗 | 典型控制端 |
|---|---|---|---|---|---|
| LoRa | 433MHz | 数 km（空旷） | 0.3~62.5kbps | 低（接收 ~10mA） | 另一台 LoRa 设备/遥控器 |
| WiFi | 2.4GHz | 30~100m | Mbps | 高（峰值 ~300mA） | 手机/网页/云（HTTP/MQTT） |
| BLE | 2.4GHz | 10~30m（长距模式更远） | 1Mbps | 低 | 手机 App（GATT） |

### 16.2 架构

```
控制端 ──┬── LoRa 433MHz（远程，点对点/组网）
         ├── WiFi 2.4GHz（局域网/云）
         └── BLE 5.0（近距离 App）
              │
              ▼
       命令仲裁层（固件）
        ├── 任一通路可控制（互为备份）
        ├── 关键命令重复确认（2s 窗口内重复 2 次，防误触发）
        ├── 双通路交叉确认（可选增强）
        └── 心跳健康监测 + 状态多通路回读
              ▼
         LTC7004 INP → 高边开关
```

### 16.3 硬件影响

- **天线**：ESP32-C6 模组自带 PCB 天线（WiFi/BLE 共用），E22 独立 433MHz 天线，频段互不干扰；模组天线需板边净空（见 §12.5）
- **功耗**：WiFi 开启峰值电流已在电源树设计余量内（3.3V 轨按 650mA 设计）
- **无新增 BOM 器件**

### 16.4 验证模式（固件阶段决策，不影响当前硬件验证）

验证模式（互为备份 / 重复确认 / 双通路交叉确认 / 状态回读）与控制端形态均属**固件层决策**，可在硬件验证完成后随时调整，对硬件方案无影响。硬件仅需保证：三通路引脚已分配（§10），ESP32 模组天线按板边净空布局（§12.5）。
