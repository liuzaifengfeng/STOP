# 被控端 Beta 固件

用 VS Code 打开仓库，在 PlatformIO 中选择 `Assused/platformio.ini` 编译被控端，`STOP/platformio.ini` 编译控制端。两端 BLE GATT UUID 和 STOP 帧外层格式保持一致；被控端 `product_id=0x0002`、镜像项目 `STOP_RX`，控制端 `product_id=0x0001`、镜像项目 `STOP_TX`。首次升级到这组项目标识需要分别 USB 烧录；后续 OTA 校验项目标识，镜像不能交叉刷写。

被控端串口监视器设为 **115200 baud**。开机打印 GPIO21 断电状态、引脚配置、NVS/INA226/VIN/E22/BLE 初始化结果；运行中每 10 秒打印一次安全状态、配对/心跳状态、按键电平、输入与输出电压及电流。若打开监视器时已错过开机阶段，可按板上复位键重看初始化日志。串口日志不会打印配对密钥。

BLE 广播名称为 `STOP-C6-RX`。名称保留在主广播中供网页筛选，128 位服务 UUID 放在扫描响应中，避免两者与 Flags 合计超过传统广播的 31 字节限制。刷入新固件后，启动日志应出现 `Advertising as STOP-C6-RX`。

## 引脚与功能

| 功能 | GPIO | 固件行为 |
|---|---:|---|
| E22 UART TX/RX、M0/M1、AUX、NRST | 4/5、2/3、14、1 | 沿用两端相同 E22 配置 |
| INA226 SDA/SCL | 22/19 | 读取输出电压、电流，7A 硬件锁存告警 |
| VIN ADC | 0 | 按实装 R10=100kΩ、R11=10kΩ 计算输入电压 |
| 本地按键 | 6 | 输入上拉；按下接地 |
| WS2812 | 20 | 状态灯，绿色供电、蓝色配对、红色故障 |
| MCU_ENABLE | 21 | 上电先拉低，只有安全状态机允许时拉高 |

网表将 R11 错标为 100kΩ，实装为 10kΩ；首次接入 6S 前仍应测量 GPIO0 电压，25.2V 输入时理论值约为 2.29V。旧设计文档将 INA226 SDA 写为 GPIO18，实际模组 28 脚对应 GPIO22。WS2812 由 5V 供电、数据由 3.3V GPIO20 直驱，需在实物上确认不同供电电压下的点亮可靠性。

## 首次配对与恢复

1. 两端上电，控制端使用**常闭**急停触点：正常释放时 GPIO6 由触点接 3.3V 为高，按下断开后由内部下拉变低。若实测相反，先修正接线，不要上负载。
2. 被控端输出保持断开。按住其本地按键 **8 秒**，达到 8 秒时立即打开 30 秒配对窗口；也可在网页“配对与联调”页点击“被控端进入配对模式”。控制端会周期发送配对请求；被控端收到后保存控制端身份和密钥，并回发配对确认。配对结束后等待连续安全心跳，满足条件即自动供电。串口打印按下、松开、持续时长及窗口结果；灯色依次为青色（按下）、黄色（满 3 秒）、紫色（满 8 秒）。
3. 上电后无需本地复位或网页使能：已配对控制端急停释放、连续收到 3 帧认证安全心跳、INA226 有效、VOUT 小于 2V、电流正常且无 OTA，自动闭合输出。VIN 检查当前已禁用。
4. 急停、超过 800ms 未收到有效心跳、控制端重启、INA226 故障、过流、输出电压异常或 OTA 都断开输出。急停松开、失联恢复或控制端重启后，重新连续收到 3 个安全心跳且电源检查通过，自动供电。硬件故障、OTA 和网页手动断电仍阻止自动使能。

控制端每约 200ms 发送认证心跳，急停边沿额外发送 3 帧。无线安全帧采用身份、启动随机数、递增序号和截断 HMAC-SHA256；外层仍是原 E22 长度与 CRC 封装。配对密钥在配对窗口内经无线明文传输，所以此 Beta 配对**不能抵御主动监听或伪造攻击**，不得当作符合工业安全认证的急停系统。实际急停响应、抗干扰、器件温升和输出断开效果必须在限流电源与负载上测量。

## BLE 状态兼容

`DEVICE_STATUS_EVENT` 原 21 字节不变；被控端追加：21～22 字节有符号小端输出电流 mA，23 字节 bit0 为 INA226 读数有效、bit1 为电流超过 7A，24～25 字节为小端 VIN mV。原 `batteryMv` 字段在被控端表示 **VOUT mV**，SOC 为未知 `0xFF`。安全状态字节 19：1 未配对、2 断电、3 供电、4 失联、5 硬件故障、6 配对中。BLE 诊断手动发包禁止 `SR` 安全帧头，BLE 临时调试使能同样必须通过固件安全检查。

控制端状态帧从 21 字节扩展到 28 字节：字节 21 为 bit0 已配对、bit1 急停触点正常、bit2 OTA 维护停机；22～27 是配对目标 BLE MAC。被控端状态帧从 26 字节扩展到 33 字节：字节 26 为 bit0 已配对、bit1 远端允许、bit2 有效心跳未超时、bit3 本地键按下、bit4 输出接通；27～32 是配对目标 BLE MAC。未配对时目标 MAC 全为 0。网页通过这两个 MAC 判断当前连接的两台设备是否真的互配。

## 台架验收顺序

1. 不接负载，用 12V 限流电源（先限流 0.5A）上电；测 5V、3.3V、GPIO0、GPIO21 与 VOUT，要求 GPIO21=低、VOUT 接近 0。
2. 用万用表确认控制端急停触点：正常释放 GPIO6=高，按下锁存 GPIO6=低；被控端本地键松开=高、按下=低。
3. 完成配对后，接 12V/约 1A 阻性负载，长按被控端本地键 3～7 秒并松开；核对 VOUT、电流和网页状态。
4. 依次按下急停、关闭控制端电源、遮断无线并重启控制端，检查每次都断电；急停松开、失联恢复和控制端重启后，均须重新累计 3 个安全心跳并通过电源检查才能自动供电。再测试 INA226 拔线/故障、OTA 期间禁止合闸、异常 VOUT 反馈。
5. 最后才逐步提高到 5A，并测 MOS、分流电阻、接线端子温升；确认 R3 实际额定功率。7A 硬件告警应在限流电源和合适测试负载下单独验证。

## GPIO6 故障时的临时调试入口

更新 Assused 被控端固件和网页后，在“配对与联调”页连接被控端：

1. 点击“被控端进入配对模式（30 秒）”，替代本地长按 8 秒。
2. 配对完成、控制端急停释放且安全心跳有效后，点击“临时调试：安全使能输出”，替代本地长按 3 秒。该操作会实际接通输出。
3. “断开输出”可主动断电；急停、心跳超时和电源保护仍然有效。急停松开或失联恢复后，连续安全心跳允许自动供电；硬件故障和手动断电不自动恢复。

使能仍检查 E22、已配对、连续 3 个安全心跳、心跳未超时、配对窗口关闭、VIN 9～30 V、VOUT <2 V、电流 <5.5 A、INA226 告警清除成功和 OTA 未进行；硬件故障锁存时拒绝使能。网页会读回实际输出状态，拒绝原因详见被控端串口。旧固件不支持使能命令，请先更新固件。

临时 BLE 命令 0x14：请求负载为 1 字节（0=断开，1=安全使能），成功响应为空；安全条件不满足返回 SAFETY_LOCKOUT，非法参数返回 INVALID_ARGUMENT。命令不模拟 GPIO6 电平，串口 key=released 仍表示物理引脚读数。

## 当前临时变更：禁用 VIN 输入 ADC

模组返修后 GPIO0 输入电压采样异常，当前 VIN_MONITOR_ENABLED=0（src/vin_monitor.h）。不初始化/读取 VIN ADC，也不执行输入电压使能门槛、运行欠压/过压或 ADC 初始化故障锁存。串口显示 VIN=DISABLED，BLE 状态第 23 字节 bit2=1，网页显示已禁用。输出电压、电流、急停、心跳、OTA 和 INA226 故障保护仍有效。修复并校准后将开关改回 1 重新编译，即恢复 VIN 检测。

## 当前临时变更：禁用断电后残压锁存

空载输出电容放电较慢，当前 src/receiver_safety.c 中 OUTPUT_OFF_VOLTAGE_PROTECTION_ENABLED=0，禁用断电超过 3 秒仍高于 2V 时的 OUTPUT_STILL_ON_mV 故障锁存。开机串口打印保护 DISABLED。使能前 VOUT <2V、使能 500ms 后 VOUT >=5V、过流、INA226 读取故障、急停和心跳保护仍保留；STOP 回执仍检查输出电压并如实标明是否已确认低于 2V。可改回 1 重新编译恢复本保护。

## 上电自动跟随控制端

当前上电默认允许自动使能；已经配对的控制端释放急停、连续 3 个认证安全心跳且现有输出/电流检查通过，即自动供电。未配对、急停按下、失联和配对中保持断开；恢复有效链路后重新累计 3 帧。网页“断开输出”禁止本次运行自动使能，需再次手动使能或重启；硬件故障锁存和 OTA 不自动解除。
